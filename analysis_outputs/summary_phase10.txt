AVISOS / NOTAS
------------------------------------------------------------------------------------------------------------------------
- WARNING: The aligned input/target analysis uses a stratified patch sample containing <5% of all patches. Inverse stratum weights are used.
- NOTE: ERA5 fields have been spatially mapped to the CorrDiff grid. Fine-grid values must not be interpreted as independent meteorological observations below ERA5 native effective resolution.
- NOTE: Smoothing-window associations are a screening analysis of local context. Formal scale decomposition is deferred to Phase 11.
- NOTE: Within-patch event contrasts compare predictor means in event pixels against non-event pixels of the same patch, reducing large-scale background and seasonal confounding but not establishing causality.
- NOTE: Cross-offset associations use predictor(x) versus radar(x+delta). A stronger displaced association can reflect spatial organization, interpolation, advection, or patch geometry and must not be read as causal displacement.
- NOTE: Overlapping patches duplicate physical pixels and pixel pairs. Weighted observation mass is not an independent sample size.
- NOTE: bulk_wind_diff variables are vector wind differences in m/s, not height-normalized vertical shear.
