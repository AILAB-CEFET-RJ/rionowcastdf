AVISOS / NOTAS
----------------------------------------------------------------------------------------------------------------------------
- WARNING: The multivariate analysis uses a stratified sample containing <5% of all patches. Inverse stratum weights are used.
- NOTE: All overlapping patches from the same timestamp fall in the same temporal period, but adjacent timestamps can belong to the same weather system.
- NOTE: Forward folds are provisional. Phase 15 remains responsible for the formal train/validation/test split.
- NOTE: The month x local-hour climatology is fit using training rows only in each fold.
- NOTE: Logistic and ridge coefficients use weighted standardized features. Collinearity can redistribute coefficient weight among correlated predictors.
- NOTE: PCA uses the weighted correlation matrix of the 20 patch-mean predictors and diagnoses redundancy, not supervised importance.
- NOTE: HistGradientBoosting is only a nonlinear screening model; hyperparameters are fixed rather than tuned.
- NOTE: means_plus_std adds within-patch variability but is not the formal ablation study planned for Phase 17.
- NOTE: Metrics are weighted to approximate the original patch distribution. Weighted patch mass is not an independent sample size.
- NOTE: Pixel fractions remain properties of overlapping patches, not de-duplicated full radar fields.
- NOTE: All multivariate results are descriptive/predictive screening and do not establish causality.
