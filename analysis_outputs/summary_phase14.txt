AVISOS / NOTAS
------------------------------------------------------------------------------------------------------------------------------------
- WARNING: All target/radar shift results are conditioned on timestamps with radar availability. Coverage shift is therefore analyzed explicitly and must be considered before interpreting physical change.
- WARNING: Predictor shift uses timestamp-level ERA5 summaries from Phase 6, not the full native ERA5 fields.
- WARNING: Absolute predictor shift can include seasonal-composition effects. A reference month x local-hour anomaly representation is reported separately.
- WARNING: Reference climatologies for anomaly-space comparisons are fit only on the reference period of each comparison.
- WARNING: Regime shift uses Phase 13 KMeans assignments. Regimes are statistical states, not unique physical weather classes.
- WARNING: Daily block bootstrap preserves within-day temporal dependence but does not eliminate dependence across adjacent multi-day weather systems.
- WARNING: Event-rate decomposition is exact for the chosen regime partition and observed radar-available timestamps, but it is not a causal decomposition.
- WARNING: The 2024 record should be interpreted with particular care if its radar availability differs substantially from earlier years.
- WARNING: Phase 14 diagnoses dataset/relationship shift. It does not itself define the final train/validation/test split; that is Phase 15.
- NOTE: The F5-oriented comparison uses 2011-2022 as reference and 2023-2024 as evaluation because Phase 12 showed its strongest performance degradation in the final forward fold.
- NOTE: Year-specific comparisons use 2011-2020 as a fixed historical reference to make 2021, 2022, 2023 and 2024 directly comparable.
- NOTE: Predictor shift reports standardized mean difference, KS, PSI and standardized quantile shifts. No single statistic should be treated as a standalone definition of distribution shift.
- NOTE: Regime-composition shift reports Jensen-Shannon divergence, total-variation distance and per-regime prevalence deltas.
- NOTE: Conditional radar shift compares P(event | regime) between reference and evaluation windows with UTC-day block-bootstrap confidence intervals.
- NOTE: The symmetric Shapley decomposition separates the observed event rate change into regime-composition and within-regime components that sum exactly up to numerical rounding.
